## Setup

- Install Homebrew
- Install dependencies:  `brew bundle install`

## Commands

- Build: `task build`
- Run Tests: `task test`
- Run tests with code coverage: `task coverage`
- Lint code: `task lint`
- See available commands: `task --list`
